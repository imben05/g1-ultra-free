# g1-ultra-free

Module Shadowrocket (iOS) tách riêng để dò và mở khóa mã **Google AI Ultra 30 TB (free 1 tháng / giảm 90%)** trực tiếp trên trang `one.google.com/ai`.

## Link cài Module (Shadowrocket → Cấu hình → Modules → `+`)

```
https://raw.githubusercontent.com/nmchien123/g1-ultra-free/main/g1-ultra-free.sgmodule
```

## Bảng ánh xạ nút (tab Hàng tháng)
| Nút bấm trên Google App | Mã SKU được gọi |
|---|---|
| **30 GB** | `g1.ios.30tb.ai.pro.m` |
| **Basic 100 GB** | `g1.30tb.1month_eft` |
| **AI Plus 400 GB** | `g1.ai.ultra.1month_eft` |
| **2 TB** | `g1.ai.pro.1month_eft` |
| **AI Pro 5 TB** | `g1.ai.ultra.3months_ip_90p.acq` |
| **Ultra 20 TB** | `g1.ios.30tb.m` |

## Cách dùng
1. Tắt tạm các module `G1` khác, chỉ bật **`G1 Ultra Free Test`**.
2. Bật VPN Shadowrocket → mở **Google App → Quản lý Google One**.
3. Chạm thử từng nút **«Bắt đầu»** (chỉ xem bảng App Store bật lên, chưa bấm Confirm). Thanh xanh mỏng trên cùng bấm vào để mở/ẩn bảng tra cứu nút.
